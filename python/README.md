# Python utilities

Small standard-library Python examples designed to be readable and easy to test.

Run all project tests from the repository root:

```bash
python -m unittest discover -s tests -v
```

Modules:
- `text_utils.py`: normalize text, count words, and check palindromes.
- `validators.py`: validate common input formats.
- `statistics_utils.py`: descriptive statistics without third-party dependencies.
