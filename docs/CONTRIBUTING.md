# Contributing

## Workflow

1. Create a focused branch.
2. Make one coherent change.
3. Add or update a test.
4. Run the relevant checks.
5. Use a descriptive commit message.

## Commit message examples

- `feat(python): add input validation helper`
- `test(algorithms): cover empty binary search input`
- `docs(sql): explain window function example`

## Quality checklist

- Inputs are validated where appropriate.
- Public functions have docstrings or comments explaining non-obvious behavior.
- Tests cover normal cases and important edge cases.
- No secrets, private data, or generated build artifacts are committed.
