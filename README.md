# Yash's CSE Project Portfolio

A practical collection of small, tested projects and exercises covering computer science fundamentals, Python, JavaScript, SQL, algorithms, automation, and web development.

## Repository map

- `python/` — reusable Python utilities and beginner-friendly examples
- `algorithms/` — classic data structures and algorithms with explanations
- `javascript/` — browser and Node.js utilities
- `sql/` — schema design and analytical queries
- `web/` — a responsive portfolio starter
- `automation/` — safe local workflow helpers
- `tests/` — automated checks
- `docs/` — setup notes and contribution guide

## Getting started

Python examples use the Python 3 standard library unless a folder README says otherwise.

```bash
python -m unittest discover -s tests -v
```

For JavaScript utilities, use a current Node.js LTS release:

```bash
node javascript/string-tools.js
```

## Engineering principles

1. Prefer readable, tested code over clever shortcuts.
2. Keep examples small enough to understand and extend.
3. Document assumptions, input constraints, and edge cases.
4. Never commit credentials, private datasets, or personal information.
